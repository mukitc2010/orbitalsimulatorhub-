## ⚡ 3-Step Setup

### Step 1: Get OpenAI API Key
1. Visit: https://platform.openai.com/api-keys
2. Create new key
3. Copy it

### Step 2: Add to n8n
1. n8n → **Settings** → **Credentials**
2. **Add Credential** → **OpenAI**
3. Paste API key → Save

### Step 3: Import Workflow
1. n8n → **Workflows** → **Import from File**
2. Select: `n8n/workflows/ai-topic-generator.json`
3. Connect OpenAI credential to "OpenAI Generate Topics" node
4. Toggle **Active** ON

**Done!** AI generates topics daily! 🎉
