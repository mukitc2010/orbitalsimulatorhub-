# Store listing assets

Ready-to-upload marketing assets for both stores. All screenshots were captured
from the real running app and framed with captions.

## ios/ — App Store Connect
Six screenshots at **1320×2868** (iPhone 6.9" display class). Upload under
App Store → iOS App → Screenshots. Suggested order: 1-home, 2-sim, 3-multi,
4-oracle, 5-learn, 6-quiz.

## android/ — Google Play Console
- Six phone screenshots at **1080×2340** (upload under Store listing → Phone screenshots)
- `feature-graphic-1024x500.png` — required Play Store feature graphic
- `play-icon-512.png` — required 512×512 app icon

Store copy (descriptions, keywords, category) is in ../APP-STORE-PUBLISHING.md.
Regenerate any of these by rerunning the app and capturing at the same sizes.
