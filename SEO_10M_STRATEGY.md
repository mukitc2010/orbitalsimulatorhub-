## PART 2 — ON-PAGE SEO FOR FEATURED SNIPPETS

### Featured Snippet Targets (Position 0)
Structure content to answer:
- **What is X?** — Definition + 40–60 words
- **How does X work?** — Numbered steps, tables
- **How many/much X?** — Direct answer first
- **X vs Y** — Comparison tables

### High-Value Questions to Dominate
| Question | Page | Format |
|----------|------|--------|
| How fast does ISS orbit? | /calculators, /satellites | Direct answer + formula |
| How many astronauts on Moon? | /astronauts | List + names |
| What is LEO MEO GEO? | /learn/how-satellites-work | Table + definitions |
| How does satellite orbit simulator work? | /simulator | HowTo steps |
| What is orbital mechanics? | /learn/orbital-mechanics | Definition + examples |
| How do satellites stay in orbit? | /learn/space-questions | Physics explanation |
