# Reinforcement Learning for Satellites: Training AI in Orbit

Reinforcement learning (RL) is transforming how we design autonomous spacecraft. Unlike traditional control, which requires accurate models and hand-tuned gains, RL agents learn optimal policies by interacting with their environment—receiving rewards for good behavior and penalties for bad. For satellites, this means collision avoidance, formation flying, and trajectory optimization can be learned in simulation and deployed in orbit. This article explains the fundamentals and the path from lab to space.

## The RL Framework

An RL agent observes a state \(s\), takes an action \(a\), and receives a reward \(r\). The goal is to maximize cumulative reward over time. Formally, we seek a policy \(\pi(a|s)\) that maps states to actions. For a satellite, the state might be position, velocity, and the positions of nearby objects; the action might be a thrust vector; the reward might be +1 for avoiding collision and -1000 for a crash. The agent learns by trial and error, gradually discovering which actions lead to high rewards.

## Policy Gradients vs. Value-Based Methods

Two main families exist. **Value-based methods** (e.g., Q-learning) estimate the expected return for each state-action pair and choose the action with the highest value. **Policy gradient methods** (e.g., PPO, SAC) directly optimize the policy parameters using gradient ascent on the expected return. For continuous action spaces—like thrust vectors—policy gradients are often preferred. For discrete decisions—like which maneuver to execute—value-based methods can be simpler.

## The Simulation-to-Reality Gap

RL is typically trained in simulation. Orbital mechanics are well-modeled; we can simulate thousands of scenarios in parallel. But simulation is never perfect—solar radiation pressure, J2 perturbation, and sensor noise differ from reality. **Domain randomization** helps: vary parameters (mass, drag, noise) during training so the agent becomes robust. **Sim-to-real transfer** is an active research area, with techniques like system identification and fine-tuning on limited real data.

## Collision Avoidance: A Case Study

Consider a constellation of 500 satellites. Each must avoid collisions with neighbors and debris. The state space is huge; the dynamics are nonlinear. RL can learn a policy that, given local observations (relative positions and velocities), outputs a safe maneuver. Training in simulation with randomized initial conditions and disturbance forces produces agents that generalize to novel scenarios. SpaceX and others use similar approaches for autonomous collision avoidance.

## Key Equations

The Bellman equation for value-based RL:

\[
V(s) = \max_a \left[ r(s,a) + \gamma \sum_{s'} P(s'|s,a) V(s') \right]
\]

For policy gradients, we maximize expected return:

\[
J(\theta) = \mathbb{E}_{\pi_\theta} \left[ \sum_t \gamma^t r_t \right]
\]

and update parameters via the policy gradient theorem.

## Key Concepts

- **Policy** = Mapping from state to action
- **Reward** = Scalar feedback signal
- **Value function** = Expected future return from a state
- **Sim-to-real** = Transferring learned behavior from simulation to hardware
- **Domain randomization** = Training with varied parameters for robustness

## Why It Matters

RL enables autonomous behavior in complex, uncertain environments. As satellite constellations grow and missions push beyond Earth orbit, hand-coded control becomes impractical. RL offers a scalable alternative: train in simulation, deploy in space, and let the agent adapt to conditions that designers never anticipated.
